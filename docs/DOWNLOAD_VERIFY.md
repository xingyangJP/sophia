# 実モデル取得での検証 —— 走らせる前に判定を決める

| 項目 | 内容 |
|---|---|
| 記録日 | 2026-09-05 |
| 対象 | モデル取得の停止検知（`ModelDownloadStallWatch` / Issue #48 の誤検知） |
| 状態 | **手順のみ。まだ走らせていない** |

> **数字を見てから判定を決めると、望む側に読める。** 15.8節の作法どおり、**先に書く。**

---

## 何を確かめるのか

**事故の再現条件は既に分かっている**（2026-09-05 の調査）:

```
UI       14,275,517 / 4,622,110,691 bytes で 65秒 停止 → watchdog がキャンセル（-999）
OSログ   同じ HTTP 200 通信が 376,081,675 bytes を受信していた（UI の約26倍）
原因     swift-huggingface 0.9.0 の downloadSnapshot 進捗が大容量ファイル中に更新されない
```

**確かめるのは1つだけ:**

> **`Progress` が止まっている間に、ディスク側の信号が生きていて、打ち切られないこと。**

---

## 走る前の門（すべて満たすまで走らせない）

| # | 条件 | 判定 |
|---|---|---|
| 0-1 | ビルド／実測を保持している | `XCBBuildService` / `swift-frontend` / `xctest` が 0 件 |
| 0-2 | **単体テストが緑** | `make app-test` が `** TEST SUCCEEDED **`。**印の本数と内訳を控える** |
| 0-3 | **Sophia が起動していない** | `pgrep -x Sophia` が空（**2部起動すると測るのは取得ではなくメモリ争奪になる**） |
| 0-4 | **ログを残す形で起動する** | `make app-watch`（`logs/mlx-stats.log` へ stderr を落とす） |
| 0-5 | **前後で一時ディレクトリの状態を取る** | `du -sh ~/Library/Containers/jp.co.xerographix.sophia/Data/tmp` |

**⚠ 既存の一時ファイル約 7.3GB は削除しない**（利用者の確認が別途要る）。
**観測関数は `modified >= startedAt` で古い残骸を除いているので、消さなくても判定は汚れない**
── **そのこと自体が、この検証で確かめる対象でもある。**

---

## 判定 —— **データを見る前に決めた**

### 合格（すべて満たすこと）

| # | 条件 | なぜ |
|---|---|---|
| **A1** | **65秒を越えて取得が続く** | 事故は65秒で打ち切られた。**越えたこと自体が第一の証拠** |
| **A2** | `stalled` の行が**出ない** | 打ち切っていない |
| **A3** | ログに **`disk_bytes=` が 0 でない値**で出る | **ディスク信号が武装し、実際に観測できている**（0 のままなら、判定は `Progress` だけで下っている＝直っていない） |
| **A4** | **`disk_bytes` が単調に増える区間がある** | 観測が本物のファイルを見ている |
| **A5** | 取得が完了し、**展開へ進む** | 欠陥2（完了した取得を展開中に打ち切る）が起きていない |

### 不合格（1つでも当たれば直っていない）

| # | 症状 | 何を意味するか |
|---|---|---|
| **B1** | `stalled` が出る | **打ち切りが残っている。** `disk_bytes` と `disk_idle_s` の値で、どちらの信号が死んでいたかを読む |
| **B2** | `disk_bytes=0` のまま進む | **観測点が違う**（サンドボックス内の `temporaryDirectory` を見ていない） |
| **B3** | 取得完了後、展開中に `stalled` | **欠陥2が残っている。** `snapshotIsComplete` が真を返していない |
| **B4** | 取得が**完了してしまい 65秒に届かない** | **事故を再現できていない。** 合格でも不合格でもない ── **判定不能として記録する** |

> **B4 を「合格」と書かないこと。** キャッシュが効いて速く終われば、**この検証は何も測っていない。**
> その場合は**取得済みのスナップショットを退けてやり直す**か、**判定不能のまま残す。**

## 出すもの

**要約しない。** 各段で:

1. **実行したコマンドそのもの**
2. **`logs/mlx-stats.log` の `event=` 行を丸ごと**（`tick` / `idle` / `stalled`）
3. **前後の `du -sh` と `pgrep -x Sophia`**
4. **満たした R の番号を、数字より前に**

**取れなかったものは「取れなかった」と書く。埋めない。**（R7）
